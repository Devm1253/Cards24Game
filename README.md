
# Card 24 Game

A JavaFX application where players use four randomly generated playing cards to create a mathematical expression that equals 24.

## Features
- Displays four randomly generated cards without duplicate values
- Supports addition, subtraction, multiplication, and division
- Supports parentheses and order of operations
- Verifies that each displayed card is used exactly once
- Shows feedback for correct and incorrect answers
- Refresh button generates a new set of cards
- Dark-themed interface with custom playing card images

## Technologies
- Java
- JavaFX
- FXML
- CSS
- Maven

## How to Play
1. Launch the application.
2. Look at the four displayed cards.
3. Enter an expression using all four card values exactly once.
4. Click Verify to check your answer.
5. Click Refresh to generate new cards.

Ace = 1, Jack = 11, Queen = 12, King = 13.
